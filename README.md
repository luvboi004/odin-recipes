# Odin Recipes

A beginner-friendly static recipe website built with HTML. The project practises core HTML structure, headings, lists, images, links, and navigation between pages.

## Recipes

- **Creamy Garlic Alfredo Pasta** — `recipes/pasta.html`
- **Chocolate Mug Cake** — `recipes/mugcake.html`
- **Mango Lassi** — `recipes/mangolassi.html`
- **Bread Pizza** — `recipes/breadpizza.html`

## Run locally

No installation or build step is required. Clone or download the repository and open `index.html` in a web browser. You can also open the folder in VS Code and use a local preview extension such as Live Server.

## Built with

- HTML5

This is a small learning project focused on semantic HTML and basic multi-page website navigation.
